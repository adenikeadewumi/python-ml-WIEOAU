# 📚 Course Glossary: AI, Data Science & Python

Welcome, Detective! This is your field reference guide. When you encounter a term in a lecture or a Kaggle notebook that makes you pause, look it up here.

---

## 🐍 Python & Coding Basics
* **Debugging**: The process of finding and fixing errors (bugs) in your code.
* **Function**: A reusable block of code that performs a specific action. You define it once and use it many times.
* **Library**: A collection of pre-written code that you can import to do complex tasks without writing them from scratch (e.g., Pandas, NumPy).
* **Script**: A file containing Python code that is meant to be executed (usually ending in `.py`).
* **Virtual Environment**: A "sandbox" folder for a project. It keeps the libraries for *this* project separate from your computer's global libraries so you don't break things.

## 📊 Data Handling (NumPy & Pandas)
* **Array**: A data structure (from NumPy) that holds numbers. It is like a list, but optimized for high-speed mathematical calculations.
* **DataFrame**: The core object in Pandas. Think of it as a super-powered spreadsheet (rows and columns) that you can programmatically manipulate.
* **Feature**: An individual piece of data you use to train your model (e.g., the 'Square Footage' in a house price prediction model). Also called a *column* or *input variable*.
* **Vectorization**: Performing an operation on an entire array at once rather than using a loop (a key skill for fast data science!).

## 🤖 Machine Learning & AI
* **Algorithm**: The set of mathematical rules the computer follows to learn patterns from data (e.g., Linear Regression, Decision Trees).
* **Hyperparameter**: "Settings" you choose *before* you train the model (like the "speed" of learning). You don't learn these; you tune them to improve accuracy.
* **Label (or Target)**: The answer you want the model to predict (e.g., the final price of a house).
* **Model**: The output of an algorithm after it has been trained on data. It is the "brain" that you use to make predictions.
* **Overfitting**: When your model learns your training data *too* perfectly, including the noise. It works great on the practice test but fails on real-world, new data.
* **Test/Train Split**: Dividing your data into two sets: one to teach the model (Train) and one to verify it actually learned something (Test).
