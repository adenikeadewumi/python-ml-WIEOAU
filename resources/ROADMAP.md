# 🗺️ Course Roadmap

Welcome! This visual roadmap outlines your journey from a complete beginner to a Machine Learning practitioner. Use this to track your progress and understand how each module builds upon the last.

![Course Roadmap](resources/assests/Roadmap.jpg)

---

## 🧭 The Learning Path

### Phase 1: Python Foundations
*Focus: Mastering the syntax and logic.*
* **00. Setup:** Getting your environment ready.
* **01-04:** Basics, Data Structures, Control Flow, and Functions.
* **05-09:** Object-Oriented Programming (OOP), Modules, Error Handling, and Advanced Python.

### Phase 2: Data Science Stack
*Focus: Data manipulation and visualization.*
* **10. NumPy:** Mastering arrays and mathematical operations.
* **11. Pandas:** Dataframe manipulation and cleaning.
* **12. Visualization:** Plotting data with Matplotlib/Seaborn.
* **13. ML Intro:** Workflow, metrics, and data preparation.

### Phase 3: Machine Learning
*Focus: Predictive modeling.*
* **14. ML Algorithms:** Linear Regression, Decision Trees, SVM.
* **15. Deep Learning:** Neural Networks and Keras.

---

*Pro-Tip: If you feel stuck on a specific module in Phase 3, it is usually a sign to revisit the foundational tools in Phase 2!*
