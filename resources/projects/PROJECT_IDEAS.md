# 🚀 Project Portfolio: Ideas & Guidelines

This directory contains capstone projects. The goal here is to move from "learning code" to "building software."

## 🟢 Phase 1: Foundations (Python Basics)
*Goal: Master logic, syntax, and automation.*

1. **CLI To-Do List:** Build a command-line app to add/remove tasks. *Guide: Use lists for storage and `while` loops for the interface.*
2. **Password Generator:** Randomly generate complex passwords. *Guide: Use the `random` and `string` modules.*
3. **Word Frequency Counter:** Analyze a `.txt` file to find the most common words. *Guide: Use dictionaries for counting and `file I/O` to read.*
4. **Student Grade Manager:** Create a system to input grades and calculate GPA. *Guide: Use dictionaries to map student names to lists of grades.*
5. **Expense Tracker:** Save expenses to a file and display the total. *Guide: Practice writing and appending to `.csv` files.*

## 🔵 Phase 2: Data Science (Pandas & Visualization)
*Goal: Data cleaning, analysis, and storytelling.*

6. **CSV Data Cleaner:** Take a messy dataset and automate the cleaning process. *Guide: Use Pandas to handle missing values and drop duplicates.*
7. **Personal Finance Analyzer:** Visualize your own bank statement (CSV). *Guide: Use Matplotlib/Seaborn to plot spending trends.*
8. **Spotify Trends EDA:** Analyze a Spotify dataset to find top artists/genres. *Guide: Use groupby operations to aggregate data.*
9. **Stock Market Visualizer:** Fetch basic stock data and plot closing prices. *Guide: Use `yfinance` to get data and `matplotlib` for lines.*
10. **Weather Dashboard:** Clean and analyze historical weather data for your city. *Guide: Compare yearly temperature averages.*

## 🟣 Phase 3: Machine Learning (Scikit-learn & Deep Learning)
*Goal: Predictive modeling and AI.*

11. **House Price Predictor:** Predict prices based on square footage and location. *Guide: Use Linear Regression.*
12. **Iris Flower Classifier:** Classify species based on measurements. *Guide: Use K-Nearest Neighbors (KNN).*
13. **Sentiment Analysis:** Analyze tweets or product reviews as positive/negative. *Guide: Use NLP (TextBlob or Scikit-learn).*
14. **Spam Email Detector:** Use keyword frequency to flag emails. *Guide: Use Naive Bayes or Logistic Regression.*
15. **Credit Card Fraud Detection:** Identify anomalies in transaction data. *Guide: Focus on data imbalance (SMOTE).*
16. **Handwritten Digit Recognition:** Use the MNIST dataset. *Guide: Build a simple Neural Network (Keras/TensorFlow).*
17. **Movie Recommender:** Suggest movies based on user preferences. *Guide: Use Collaborative Filtering.*
18. **Face Detection:** Use OpenCV to detect faces in an image. *Guide: Use pre-trained Haar Cascades.*
19. **Simple Chatbot:** Create a rule-based AI that answers FAQs. *Guide: Use `if/else` logic with keyword matching.*
20. **Stock Price Forecaster:** Predict tomorrow's price based on history. *Guide: Use LSTM or Time Series analysis.*

## 🛠️ The "Build" Guide (How to approach every project)
Don't just code; follow this engineering flow:

1. **Define the Goal:** What problem are you solving?
2. **Find the Data:** If it's data science, go to Kaggle. If it's a CLI app, you define the logic.
3. **Draft the UI/Structure:** Sketch the logic on paper before writing code.
4. **Code & Break:** Expect errors. Use the `TROUBLESHOOTING.md` when you get stuck.
5. **The README:** Every project folder MUST have a `README.md` explaining *how to run it*.
