# 📂 Assets Directory

This directory serves as the central storage for all static media and visual assets used across the repository (e.g., README images, diagrams, logos, and charts).

## 📝 Guidelines for Contributors
Please follow these standards to keep the repository clean:

* **File Naming:** Use `kebab-case` with descriptive names (e.g., `roadmap-overview.png`, `ml-workflow-diagram.jpg`). Avoid spaces or special characters.
* **Optimization:** Before uploading, please compress images (e.g., use tools like TinyPNG) to ensure the repository remains lightweight and fast for students to clone.
* **Organization:** Keep this folder flat. If the number of assets exceeds 20 items, feel free to create specific sub-folders (e.g., `/diagrams`, `/logos`).

You can link to these files from any Markdown file (like `README.md` or `ROADMAP.md`) using relative paths:
