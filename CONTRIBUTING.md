# 🤝 Contributing

Thank you for helping improve this course!

## How to Contribute

1. **Fork** this repository
2. **Create a branch**: `git checkout -b fix/typo-in-module-03`
3. **Make your changes**
4. **Commit**: `git commit -m "Fix: typo in control flow notebook"`
5. **Push**: `git push origin fix/typo-in-module-03`
6. **Open a Pull Request**

## What We Welcome
- Typo and grammar fixes
- Clearer explanations
- Additional exercises
- Bug fixes in code cells
- New examples that illustrate a concept better

## What We Don't Accept (For Now)
- Entirely new modules (open an Issue to discuss first)
- Drastic restructuring of existing content

## Code Style
- Keep code cells short and focused (one concept per cell)
- Add comments explaining the *why*, not just the *what*
- Test all code before submitting

## Questions?
Open an Issue — all questions are welcome!
